*2026년 11월 7일 업데이트. 과거 결과는 원래 기록 시점을 기준으로 합니다.*

과학적 발견은 축적된 수치 방법과 분야 지식을 담은 소프트웨어에 의존합니다. Genesis의 MESA 일부 모듈 재개발은 Agentic AI를 AI for Science의 이 기반에 연결합니다. 기존 수치 동작을 보존해야 할 기준으로 삼으면서 구현을 개선합니다.

## 범위를 정한 재개발

[2026년 9월 7일 Evidence 기록](https://genesis.evox.group/evidence/mesa/)은 **13개 모듈, Fortran 139,414줄에서 Rust 89,946줄**을 보고합니다. 스냅샷 규모이며 저장소의 라이브러리 전용 줄 수와는 다릅니다.

보간, 솔버, 반응 네트워크, 상태 방정식, 불투명도 등의 수치·물리 모듈이 대상입니다. MESA 전체를 대체하지 않으며 항성·쌍성 진화 엔진 등 문서에 명시된 구성 요소는 범위 밖입니다.

## 속도보다 먼저 동작 검증

모듈마다 Rust crate가 있고 인터페이스와 제약을 기록합니다. 골든 테스트는 원래 Fortran 출력과 비교하며 통합 테스트는 모듈 사이 동작을 확인합니다.

수치 동등성에는 허용 오차와 과제가 필요합니다. 스칼라 결과 일치만으로는 해법 경로 차이를 놓칠 수 있어 단일 구역 연소 대리 과제의 적분 단계 동작도 기록합니다. 빌드 성공보다 유용한 이식 근거입니다.

## 검증 결과

저장소는 **1,052개 통과, 실패 0개, 18개 무시**를 보고합니다. 요약에도 무시된 작업을 밝혀야 합니다. Evidence의 **미화 10.64달러**는 하드웨어를 제외한 토큰 비용이며 모델, 에피소드 수, 실행 시간은 미보고입니다.

이는 프로젝트 보고이지 독립 재현은 아닙니다. 정해진 이식·평가 범위를 뒷받침하며 모든 MESA 과학 워크플로를 포함한다는 뜻은 아닙니다.

## 벤치마크 시점을 구분하기

Evidence는 중앙값 **1.55–6.87배** 가속을 보고합니다. 별도로 8월 5일 README 표는 15회 실행 중앙값을 사용하며 종단 간 단일 구역 연소 대리 과제는 **1.25배**입니다. 이를 하나의 보편적 가속비로 합치면 안 됩니다.

과제, 입력, 컴파일 옵션, 수치 허용 오차를 맞춰 비교해야 합니다. 더 빠른 보간 커널의 비율이 전체 항성 시뮬레이션의 가속비가 되는 것은 아닙니다.

## 과학 소프트웨어 현대화의 경로

[README](https://github.com/EMI-Group/genesis-demo-mesa-rs/blob/main/README.md)에 도구 체인, 빌드, 테스트, 벤치마크 절차가 있습니다. 환경 준비 후 테스트 진입점은 다음과 같습니다.

```bash
cargo test --workspace
```

[MESA 재개발 저장소](https://github.com/EMI-Group/genesis-demo-mesa-rs)는 에이전트 개발이 역사가 있는 과학 소프트웨어를 어떻게 이어 갈 수 있는지 보여줍니다. EvoX의 방향은 검증 가능한 과학적 동작을 유지하면서 인프라를 변화에 적응시키는 것입니다. 보고된 모듈을 넘어서는 확장에는 추가 분야 검증이 필요합니다.
