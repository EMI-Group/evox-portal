## Release Highlights

This is a minor release focused on improving stability and addressing bugs observed in the previous versions.

### 🐛 Bug Fixes

- Fixed an issue where the PSO algorithm would occasionally converge prematurely on specific hardware configurations.
- Resolved a compatibility issue with PyTorch 2.2.0.
- Corrected the documentation links in the CLI help message.

### 🛠️ Improvements

- **Performance**: Optimized the memory usage for large-scale population initialization.
- **Logging**: Enhanced error messages to provide more context during runtime failures.
