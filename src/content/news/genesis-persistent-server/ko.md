2026년 11월 2일 출시된 Genesis 0.14.0은 서버 시작 시 systemd lingering 상태를 확인하고 활성화 옵션을 제공합니다. 이는 10월 30일 0.13.11에서 도입한 헤드리스 배포판을 잇는 개선입니다. 개발 실행 환경의 수명 주기를 데스크톱 세션과 별도로 관리할 수 있게 합니다.

## 운영 제어를 갖춘 서버 배포판

헤드리스 배포판은 대시보드와 에이전트 실행 환경을 포함하며 Linux x64/arm64와 macOS arm64를 지원합니다. CLI는 서비스 실행, 시작, 중지, 상태, 로그, 상태 점검과 버전 확인을 제공합니다. 설치 스크립트는 체크섬을 검증하고 패키지를 설치·업그레이드하며 실행 파일을 연결합니다.

이는 지속적인 프로세스를 운영하기 위한 실용적인 인터페이스입니다. 상태 엔드포인트는 상태, 버전과 가동 시간을 반환하고 로그는 서비스 동작을 드러냅니다. 그러나 정상 프로세스가 에이전트 변경의 정확성이나 프로젝트 테스트 통과를 뜻하지는 않습니다. 런타임 상태와 소프트웨어 검증은 다른 책임입니다.

## 실행 주변의 수명 주기 관리

systemd를 사용하는 Linux에서 사용자 서비스가 로그아웃 후에도 유지되려면 lingering이 필요할 수 있습니다. 0.14.0은 이 조건을 확인하며 GENESIS_LINGER 또는 --no-linger로 설정할 수 있습니다. 플랫폼별 기능이며 모든 운영체제가 동일하게 동작한다는 뜻은 아닙니다.

이전 버전은 원격 시작도 개선했습니다. POSIX shell 래퍼로 명령을 실행하고 공백이 포함된 경로를 처리하며 연결 오류를 읽기 쉬운 이유로 표시합니다. 서버 모드 수정과 정확한 가동 시간 보고로 운영 상태를 진단하기 쉬워졌습니다.

## 배포도 개발 역량의 일부입니다

장기 개발에서는 적절한 머신에 실행을 배치하는 것도 작업 과정입니다. 서버 배포판은 명시적인 수명 주기 제어를 갖춘 배포 가능한 구성 요소를 제공해 Genesis의 진입점을 데스크톱 밖으로 확장합니다. EvoX 개발 인프라의 운영 측면을 강화하지만 검토, 검증, 수락할 결과에 대한 결정을 대체하지는 않습니다.
