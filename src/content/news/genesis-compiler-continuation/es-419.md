¿Puede avanzar un proyecto cuando cambia el modelo subyacente? El registro Compiler Continuation, del 7 de septiembre de 2026, describe la reanudación desde el repositorio aceptado del compilador sin transferir el contexto de conversación del Agent anterior.

El registro reporta un cambio de **GLM 5.2 a DeepSeek V4 Flash**, con una profundidad de recursión que pasó de **4 a 8**. La continuación aprobó **1,820/1,820 casos LLVM SingleSource conservados para la evaluación**. Es un conjunto definido, no toda la suite LLVM.

El código aceptado y el historial del proyecto sirven de base para el trabajo posterior: así ilustra Genesis la continuidad. La creación del compilador y su continuación comparten repositorio y no deben contarse como proyectos independientes.

Esta retrospectiva sigue el registro Evidence. Los resultados provienen del proyecto y no se han reproducido de forma independiente; no se publicaron el costo ni el código agregado durante la continuación. El README de la rama predeterminada describe otra evaluación, cuyos conteos no deben combinarse con este resultado.
