# Blog classification

- `releases`: the canonical announcement and upgrade reference for a published version of any ecosystem product, including EvoX, Genesis and EvoX Compiler. Preserve upstream prerelease labels for alpha, beta and RC releases.
- `news`: development progress, research, Evidence cases, community and focused technical analysis. Mentioning a version does not make a focused analysis a release announcement.
- Before drafting, choose the collection from the article's primary reader purpose. A title change does not substitute for correct collection placement.
- A release event gets one canonical release entry. A separate news analysis needs a distinct question and additional substance, with a localized link to the release entry; avoid duplicating its changelog.
- Migrations move all 13 locale files and article assets together, preserve publication dates, update internal links and automation records, and permanently redirect all old localized URLs. Verify list membership, breadcrumbs, canonical/hreflang, sitemap and social-image output on the new collection.
