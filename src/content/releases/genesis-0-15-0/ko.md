Genesis v0.15.0이 2026년 11월 27일 출시되었습니다. 최근의 프로젝트 워크벤치, 계정 설정, 작업 복구 변경을 한 버전에 담았습니다. 실질적인 이점은 작업의 연속성입니다. 실행 호스트와 프로젝트를 선택하고 모델 계정을 설정한 뒤 개발을 추적하고 미완료 작업으로 돌아올 수 있습니다. 채팅 응답을 작업 완료와 혼동하지 않는 흐름입니다. 검토, 백그라운드 작업, 컨텍스트 처리도 바뀌어 대시보드 개편 이상의 업데이트가 되었습니다. [전체 릴리스 노트][release]

![기계식 제어대에 프로젝트 장부와 열쇠, 매달린 분기 장치가 연결된 모습](./cover.webp)

*개념 일러스트: 인증, 프로젝트 맥락, 재개할 수 있는 작업을 하나의 제어 지점에 모았습니다.*

## 프로젝트와 실행 호스트를 놓치지 않기

워크벤치는 프로젝트 개요, 작업별 에이전트 점검, 공용 입력창, 인라인 작업 옵션을 통합합니다. 최근 프로젝트와 폴더 탐색으로 선택을 줄이고, VCT 워크스페이스는 프로젝트를 묶어 구성원 선택기를 제공합니다. 워크스페이스 그룹 자체에는 실행 디렉터리가 없으므로 작업 전에 구체적인 구성원을 선택해야 합니다. Source Control에서는 저장소 이력과 차이를 확인합니다. 미리 보기·고정 탭, 가운데 클릭으로 열린 상태 유지, Alt+Arrow 전환, 넘치는 항목 탐색으로 레일이 열린 뷰의 유일한 목록이 됩니다.

라이브러리와 이를 사용하는 앱 사이를 오가는 개발자에게 이는 제출 순간의 정확성과 관련됩니다. 초안, 선택한 모델, 저장소가 의도한 작업을 가리켜야 합니다. 프로젝트별 초안은 비동기 로딩 후 텍스트 외 필드도 복원합니다. 이력 검색과 필터는 탐색 후에도 범위를 유지하고, 검토 위치와 작업 필터는 노드가 바뀌어도 남습니다. 뒤늦은 프로젝트 활성화가 팔레트를 닫거나 명시적으로 선택한 개요에서 다른 화면으로 이동시키지 않습니다. [워크벤치 배경][workbench]

## 계정을 설정한 다음 모델 확인하기

브라우저의 Sign in with ChatGPT를 대시보드, 설정·환영 흐름, CLI가 함께 사용합니다. 원격 호스트에는 리디렉션 URL을 직접 붙여 넣는 경로가 있으며, 흐름을 떠나거나 닫으면 취소됩니다. 기존 공급자 계정도 Settings에서 로그인을 시작할 수 있습니다. 인증이 끝나면 설정 스냅샷과 모델 선택기를 새로 고쳐 오래된 프로필이 남지 않게 합니다. 계정 마법사는 표준화된 추론 수준과 일정 프리셋도 제공합니다. off_peak_holidays는 2025~2027년 중국의 공휴일과 대체 근무일 정적 달력을 사용하며 전 세계 휴일 서비스는 아닙니다.

사용자 정의 모델 계정은 OpenAI Chat Completions를 사용하고, ChatGPT 구독 요청에는 사용량 귀속 및 프롬프트 캐시 식별 헤더가 포함됩니다. Keenable은 선택적으로 켜는 키 없는 검색 공급자입니다. 업그레이드 후 계정 라우팅과 일정을 다시 확인하세요. 일부만 저장된 계정은 스케줄러를 중단시키지 않고 경고와 함께 기본 모델 선택으로 돌아갑니다. 로컬 노드의 식별 정보가 바뀌면 Settings는 저장을 거부하므로 노드 맥락을 다시 불러온 후 재시도해야 합니다. 이벤트 로그의 공급자 키는 가려지고 Git 작업은 프로젝트 소유권을 확인합니다. [계정 설정 흐름][accounts]

## 하위 작업을 완료시키지 않고 미완료 작업 멈추기

작업 일시 중지는 기존 drain 동작을 대체해 에이전트 트리 전체를 멈추고 동일한 에이전트 ID로 재개합니다. 영속 에이전트 상태를 활성화하면 체크포인트가 부모의 대기와 자식의 작업을 보존하며 정상 종료와 중단 후 복구를 구분합니다. Review 페이지는 실패, 취소, 보고서 없음 결과를 명시하고 적용 불가능한 동작을 제거하며 “Prepare follow-up task”를 제공합니다. needs-review 필터로 이러한 결과를 찾을 수 있습니다. [일시 중지 메커니즘][pause]

백그라운드 작업에는 전역적으로 고유한 짧은 base36 ID, 작업별 로그 경로, 충돌을 피하는 레지스트리 파일명이 부여됩니다. 보존 정책은 활동 중인 소유자를 보호하고 삭제 표식을 남겨 만료된 기록이 이유 없는 알 수 없는 ID로 바뀌지 않도록 합니다. 레지스트리 메모리 증가 문제도 수정되었습니다. 기본 커밋 단계가 실패하면 자동 커밋이 보완하며, 공동 작성자 기능을 활성화하면 병합 커밋에도 정보가 붙습니다. 추적 가능성이 개선되지만 결과를 받아들이기 전에 확인할 근거는 여전히 작업 상태와 저장소 변경입니다.

## 업그레이드 후 실제 사용하는 경로 점검하기

CONTEXT.md에 Shared/Local 범위가 추가되었습니다. 상위 컨텍스트에서는 Shared 내용만 가져오고 할당된 노드는 파일 전체를 봅니다. 범위 지정 읽기·편집 도구와 통합 컨텍스트 커밋은 로컬 메모가 무관한 프롬프트에 들어가는 것을 막습니다. 스트리밍 재마운트 상태, 실시간 도구 중복 표시, 보관 및 접힌 이력 제어, 시간대 검증, 유실된 원격 로딩도 수정했습니다. Phoenix, LiveView, Bandit, idna, jsv 등 관련 의존성에는 보안 수정이 포함됩니다. 밀도와 터치 영역을 통일하고 구형 페이지 진입 효과 및 중복 사이드바 뷰 목록을 제거했습니다. 데스크톱 빌드는 플랫폼별 제어 버튼이 있는 선택형 프레임리스 제목 표시줄을 지원합니다.

운영체제에 맞는 v0.15.0 데스크톱 배포 파일을 사용하세요. 헤드리스 서버는 Linux x64/ARM64와 macOS ARM64를 지원합니다. 기존 서버 설치에서는 `genesis update --check` 다음에 `genesis update`를 실행하면 사용 가능한 업데이트를 설치하고 서버를 다시 시작합니다. 설정된 데이터 디렉터리를 보존하고 해당 버전의 설치 지침을 확인하세요. 이후 실행 버전, 계정·모델 갱신, 프로젝트별 초안 하나, 소규모 작업의 일시 중지·재개를 점검하고 해당 작업의 검토 결과와 작업 로그를 확인합니다.
