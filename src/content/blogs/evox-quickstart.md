## Introduction

Evolutionary Computation (EC) is extremely powerful in real-world research, but setting up a high-performance environment can often be daunting. EvoX changes that by providing a seamless interface between EC algorithms and hardware acceleration.

In this quickstart guide, we will walk you through running your first GPU-accelerated optimization task.

## Prerequisites

- Python 3.8+
- PyTorch or JAX installed
- A CUDA-capable GPU (optional, but recommended)
