**Cambios realizados**

- Se actualizó la documentación con notas de uso y orientación para el ajuste de parámetros

- Se añadieron nuevas funcionalidades relacionadas con `vmap` y la optimización de hiperparámetros (HPO), junto con correcciones de errores

- Se corrigieron diversos problemas en la documentación

- Se resolvieron varios errores en el código de benchmarks

- Se introdujo el soporte inicial para flujos de trabajo distribuidos.
