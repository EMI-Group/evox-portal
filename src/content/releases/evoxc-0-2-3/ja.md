EvoX Compiler v0.2.3 は 2026 年 11 月 25 日（UTC）に公開され、Python wheel とソースアーカイブを提供しています。短い GitHub の説明は v0.2.2 から v0.2.3 への比較にリンクし、版を固定した変更履歴には、この配布に至る 0.2 系列の主要変更とパッケージ修正が記録されています。0.1 から移行する際の要点は、コンパイラーとランタイムの組み合わせ、物理デバイスの選択、再確認すべき数値動作です。[リリース][release] · [変更履歴][changes]

*概念イラスト：利用できるリリースには実行環境との適合が必要です。*

## コンパイラーとランタイムを揃える

IREE の追加依存関係は、コンパイラーとランタイムの両方に 3.13.0 以上 3.14 未満を要求します。コンパイル成果物はバージョンに依存するため、別の組み合わせで生成した保存済み成果物をそのまま読み込めるとは限りません。上流では llvm-cpu と、ROCm 7.1 を使う AMD Instinct MI300X 上の ROCm/HIP を再検証し、以前の IREE で失敗していたループやスキャンも確認しています。この確認は CUDA、複数 rank 実行、すべてのモデルベンチマークに及ぶものではありません。[版を固定した依存条件][requirements] · [変更履歴][changes]

アダプターはランタイムの簡便な経路に任せず、デバイスからホストへの読み戻しも制御します。計算自体は正常でも結果の取得で失敗する場合に関係する変更です。ホストメモリーにはマッピング経路を残せますが、デバイスバッファーには明示的な転送が必要です。アプリケーションの負荷を測る際は、転送時間をカーネル時間と分けて扱ってください。

## XLA プラグインを検出し、対応デバイスを選ぶ

XLA の登録時には、呼び出し側がパスを渡す前にオプションなしでプラグインを探す処理を行わなくなりました。検出は明示的なプラグインオプション、環境変数、既知の場所、インストール済み JAX プラグインパッケージを調べ、JAX 自体はインポートしません。利用可能性はオプションの揃うコンパイル・読み込み時に確認します。ビルド用ヘルパーも解決済みオプションを読み込みに渡し、コンパイル時に見つけたプラグイン設定が読み込み時に失われる問題を修正しています。[バックエンドガイド][guide]

ROCm プラグインには ROCm デバイス、CUDA プラグインには CUDA デバイスが必要です。GPU プラグインを指定しながら既定の CPU 選択を残すと拒否されます。GPU 実験では対応デバイスを選び、テンソルを明示的に移してください。ホストへ結果をコピーする前に出力の配置を確認します。また XLA の実行失敗時には、古いバッファーポインターが後の呼び出しで再利用されないよう、キャッシュした出力ポインター欄を消去します。

## 速度比較の前に意味論を再確認する

NumPy 参照インタープリターはディスパッチ計画をキャッシュし、不要になった中間値を最後の利用時に解放し、不変のホストデバイスインスタンスを共有します。公開 API の呼び出し方を変えずに、準備と割り当ての負荷を減らす変更です。変更履歴の TensorNEAT 測定は特定の負荷を対象とし、一般的な高速化倍率ではありません。

コンパイル後の剰余演算は NumPy floormod に従い、結果の符号が除数と一致します。負の入力が有用な移行テストになります。固定入力と参照出力を保存し、データ型に合う許容誤差でインタープリターとコンパイラーを比較してください。パッケージ修正では maturin が同梱する共有ライブラリのディレクトリを受け入れ、テスト済み配布ファイルを平坦に配置して、公開を妨げていた失敗を解消しています。[修正記録][changes]

## 新しい環境でアップグレードする

Python 3.11 以降が必要です。リリース資産から選んだ 0.2.3 wheel を pip で導入してください。Linux・macOS・Windows 用 wheel とソースアーカイブがあります。IREE の追加依存関係は `pip install "evoxc[iree]==0.2.3"` で導入し、両 IREE 依存関係を確認します。別配布の evoxc-hf は独自のバージョンを持ちます。`pip check` と導入版の確認に加え、代表的なグラフ、負数の剰余、デバイス往復転送を一度ずつ確かめてから、大きな負荷へ移行してください。[導入ガイド][guide]

これらのバックエンドに関わるグラフ変換、カスタム演算、明示的なコンパイル段階は、本リリースの文書と併せて[カスタムコンパイル記事][related]をご覧ください。
