## Обновление компилятора

EvoX 1.1 заменяет TorchScript на `torch.compile`. TorchDynamo захватывает графы вычислений во время выполнения Python.

## Компиляция рабочего процесса

Шаги рабочего процесса можно компилировать для совместной оптимизации поддерживаемых тензорных операций компилятором PyTorch.

## Совместимость

Захват графа зависит от операций и потока управления. Неподдерживаемый код может вызвать разрыв графа; не все вызовы библиотек Python компилируются.
