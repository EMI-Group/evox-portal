**EvoX Compiler (evoxc) v0.1.0 вышел 29 октября 2026 года.** Это компилятор тензорных графов и среда выполнения на Python для разработчиков, которым нужно анализировать, преобразовывать, сохранять и исполнять саму программу. Проект использует Apache-2.0 и требует Python 3.11 или новее.

## Программа, доступная для анализа

evoxc открывает каждый этап через `trace → lower → compile → load → run`. Фронтенд представляет вычисления в EvoXIR и экспортирует StableHLO для внешних компиляторов, выполняющих оптимизацию и генерацию кода. Промежуточные графы и артефакты можно анализировать и сохранять.

Преобразования включают `vmap`, `grad`, `jvp` и `vjp`. Для поиска нейросетевых архитектур, генетического программирования и синтеза алгоритмов `batch_functions` объединяет кандидатов с совпадающими спецификациями входов и выходов в один граф. Явный кеш компиляции помогает многократно генерировать статические программы.

## Четыре пути выполнения

NumPy — единственная обязательная зависимость и стандартный интерпретатор на CPU. Дополнительные адаптеры соединяют граф с IREE, XLA через предоставленный пользователем плагин PJRT и TVM. Бэкенд и устройство выбираются явно; покрытие зависит от адаптера. Выпуск документирует Vulkan на Mesa lavapipe и ROCm в TVM только на этапе компиляции.

README сообщает о **7,511 пройденных, 77 пропущенных, 4 ожидаемо неуспешных тестах и 0 сбоях** в наборах ядра и `evoxc_hf` при установленных IREE, TVM и torch. Это результаты проекта для данной конфигурации. Согласно репозиторию, код, тесты и документация созданы с EvoX Genesis.

## Начало работы

Установите этот выпуск командой ниже. Дополнительные адаптеры описаны в README соответствующей версии; интеграция HuggingFace распространяется отдельно как `evoxc-hf`.

```bash
pip install evoxc==0.1.0
```
