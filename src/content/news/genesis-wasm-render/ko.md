소프트웨어 시스템을 구축하려면 프로젝트가 커져도 유용한 국소 변경이 호환성을 유지해야 합니다. Genesis의 WASM Render는 그래픽 파이프라인으로 이 과제를 연구합니다. 셰이더 처리, 렌더링, API 동작이 일관된 전체를 이루는 과정은 EvoX의 Agentic AI를 시스템 구축에 연결합니다.

![와이어프레임에서 음영 처리된 픽셀 이미지로](./software-graphics-pipeline.webp)

Genesis 공개 기록은 DeepSeek V4 Flash로 개발한 TypeScript 소프트웨어 렌더러를 설명합니다. 평가 집합에서 Khronos CTS 2,017/2,019, WebGL2 1,184/1,184가 통과했습니다. 약 36달러는 하드웨어를 제외한 토큰 비용입니다. 첫·마지막 에이전트 커밋 사이 65.9시간은 저장소 기간이지 측정된 실작업 시간이 아닙니다.

[Genesis Evidence](https://genesis.evox.group/evidence/tbench-wasm/)

## 개별 코드에서 완전한 시스템으로, 무엇이 어려울까요?

WASM Render는 Terminal-Bench Challenges에 포함된 그래픽 시스템 챌린지입니다. 브라우저, GPU, 외부 런타임 라이브러리 없이 WebGL 프로그램을 실행해야 합니다.

이는 그래픽 파이프라인을 소프트웨어로 구현하는 것과 같습니다. 셰이더 프로그램을 해석하고, 그래픽을 계산하며, 수많은 인터페이스와 상태 변화의 일관성을 유지해야 합니다. 개별 기능이 동작하는 것과 전체 시스템이 함께 동작하는 것 사이에는 큰 간극이 있습니다. 이 작업을 수행하려면 AI는 여러 차례의 개발 과정에서 목표를 일관되게 유지하고, 모듈 간 의존성을 처리하며, 테스트 피드백을 바탕으로 오류를 수정하고, 최종적으로 시스템 통합과 회귀 검증을 완료해야 합니다.

초기 12시간 시험과 개발 예산이 다르므로 통과율은 통제된 순위 비교가 아닙니다. Evidence는 엄격한 0.1% 기준의 three.js 16/38, Babylon.js 13/16도 보고하며 둘 다 선별 부분집합입니다. 높은 API 적합률이 전체 시각 회귀 통과나 완전한 그래픽 호환성을 뜻하지 않습니다.

![WebGL2.0 적합성 테스트 결과와 Genesis의 Khronos CTS 테스트 기록](./wasm-render-results-en.png)

*WebGL2.0 적합성 테스트 결과와 Genesis의 Khronos CTS 테스트 기록.*

추적 텍스트 135,165줄에는 생성된 renderer.js, 외부 코드, 잠금 파일, 문서가 포함되며 렌더러 소스만이 아닙니다. 초기 자율 제출이라는 표현도 주최 측 공식 순위가 아닙니다. 결과는 프로젝트 보고이며 독립 재현되지 않았습니다.

이번 개발은 최종적으로 Khronos CTS 테스트 2,017개를 통과했으며, 모델 token 이용료는 약 미화 36달러, 캐시 적중률은 약 98%였습니다. 낮은 모델 비용으로 이처럼 대규모의 소프트웨어 개발을 지속하고 통합까지 마쳤다는 점은 Genesis가 경제적인 오픈소스 모델을 활용해 장기간의 개발을 수행할 수 있음을 보여줍니다.

## 프로젝트는 계속 진화하고, Agent는 필요할 때 참여합니다

Genesis는 재귀적 소프트웨어 진화 AI 시스템입니다. 사용자가 소프트웨어 개발 목표를 설명하면, 시스템은 그 목표를 중심으로 작업을 펼치고 필요한 곳에 국소 작업을 담당할 Agent를 배치하며, 채택된 코드와 검증 결과를 소프트웨어 프로젝트에 남깁니다.

대규모 프로젝트에 대응하는 직관적인 방법 중 하나는 Agent에 더 많은 자원을 제공하는 것입니다. 더 긴 컨텍스트, 더 오래 유지되는 세션, 더 복잡하게 미리 정의된 협업 방식 등이 여기에 해당합니다. Genesis는 개발의 연속성을 소프트웨어 프로젝트 자체에 둡니다. 최상위 목표와 제약이 개발 전반을 이끌며, 작업은 저장소 구조를 따라 재귀적으로 펼쳐집니다. Agent는 국소 작업을 처리하고 완료되면 종료하며, 후속 Agent는 그때까지 형성된 프로젝트를 이어받습니다.

앞서 Genesis는 빈 저장소에서 출발해 약 25만 줄의 코드로 이루어진 C 컴파일러를 구축하고, 모델을 바꾸면서 개발을 이어갔습니다. 이번 WASM Render 챌린지의 테스트 결과는 복잡한 그래픽 시스템 개발에서 Genesis가 갖춘 자율적 구축 및 통합 능력을 한층 더 입증합니다.

## 계속 진화하는 개방형 시스템

이 사례의 오픈 소스 가치는 시스템 구축을 검사 가능하게 만드는 데 있습니다. 인터페이스, 구현, 검증 결과가 후속 작업에 남습니다. 에이전트 과제 사이에서 유용한 변경을 축적하고 통합된 시스템의 동작으로 진전을 평가하는 EvoX의 소프트웨어 진화 방향을 발전시킵니다.
