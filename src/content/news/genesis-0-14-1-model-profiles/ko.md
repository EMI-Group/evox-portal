모델 선택에는 계정, 자격 증명과 추론 설정도 포함됩니다. 2026년 11월 8일 공개된 Genesis 0.14.1은 이 선택을 Settings, Projects, Assistant, 스케줄러와 런타임으로 이어 주어 작업의 요청과 실제 실행 사이의 차이를 줄입니다. [v0.14.1](https://github.com/EMI-Group/genesis/releases/tag/v0.14.1)

![선택된 계정 탭이 해당 모델 선택과 연결된 모습](./provider-account-continuity.webp)

## 하나의 프로필, 일관된 선택

정규화된 공급자 프로필은 계정과 모델 선택을 구분합니다. 공통 선택기는 모델과 추론 옵션을 제공하며 스케줄러 수정은 명시적 작업 선택과 저장된 전체 설정을 유지합니다. 지원되는 프로필에는 OAuth/구독 인증, 프로필별 로그인 상태와 공급자 CLI 자격 증명 파일 가져오기도 추가됩니다.

## 로컬과 원격에서 서버 하나 사용

원격 개발은 헤드리스 대시보드와 같은 genesis_server 배포판을 사용합니다. 별도 genesis_remote 배포판은 폐지됩니다. CLI로 원격 시작, 중지, 상태와 로그를 관리하며 HTTP를 유지한 채 런타임에 분산 연결을 전환할 수 있습니다.

## 업그레이드 시 설정 인계 확인

업그레이드 후 Settings에서 공급자 계정, 모델과 추론 옵션을 확인하고 명시적 모델 선택 작업도 점검하세요. 사용자 지정 OAuth 경로는 각 모델 프로필에 속합니다. 기존 데몬 스크립트를 재사용하기 전에 공유 서버 변경을 검토하세요. 전체 마이그레이션과 수정 목록은 릴리스 노트에 있습니다. [v0.14.1](https://github.com/EMI-Group/genesis/releases/tag/v0.14.1)
