长时间开发任务需要的不只是重启按钮，还需要知道哪些智能体正在工作、各自学到了什么，以及究竟能恢复哪一份文件状态。[Genesis 0.14.3][release] 于 2026 年 11 月 19 日发布，将任务级暂停与恢复、持久智能体状态、更清晰的实时活动，以及配置、审批和部署改进带入同一版本。

![分支机械树重新连接各自锚定的基座](./whole-tree-resume.webp)

*概念插画：恢复任务，需要让各分支重新接上自己的已保存状态。*

## 暂停一个任务，保留继续工作的可能
运行中的任务可以从 `pausing` 进入 `paused`。智能体完成正在执行的工具批次，为对话建立检查点，并提交工作树后再停止。已暂停的任务仍可见、可恢复，不会被记作完成或取消；恢复时沿用同一个任务 ID。

当多智能体实现工作需要跨工作时段继续时，这一区别很实用。保持任务的持久智能体状态选项开启，发起暂停，并等待状态变为已暂停后再认定工作已稳定保存。持久化默认开启，也可通过 `genesis_start_task` 的 `persistent_state` 控制。交互会话不能暂停，关闭持久化的任务无法恢复。[版本化实现][pause] 还要求存在根智能体的持久记录，仅有子智能体记录不足以重新启动目标。
## 恢复整棵树，明确文件状态边界
独立 SQLite 存储保存每个智能体的对话、运行身份，以及工具和子智能体批次进度。整树恢复时，已完成的子智能体提供已保存结果；仍在运行的子智能体从各自的持久检查点和工作树基点继续。稳定的智能体 ID 保留这些关联；身份已被占用时，系统会警告并采用回退方式。

`refs/genesis/agent-state` 下的 Git 引用让检查点提交在工作分支被回收后仍保持可达。正常暂停可从记录的暂停提交重建工作树。意外中断后，[恢复提示][notice] 会指出有保证的检查点：被终止运行中的未提交修改不保证保留。如果没有检查点，提示会解释回退到任务基点的情况。

若恢复的任务此前正在修改文件和启动作业，应先检查提示中的提交、`git status` 和 `job_list`，再决定是否重复操作。中断的工具调用得到的是修复信息，不是虚构的成功结果。此版本也修复重复创建子智能体、交互会话被错误恢复为异常暂停任务的问题，并改进回合上限恢复。
## 看见此前像是空闲的工作
检查器和 Assistant 现在读取实时活动及原子监视快照。上下文压缩与下一回合准备有独立的忙碌阶段，不再显示为空闲。Context Memory 将实时调用作为尾部行展示，历史推理保持静态。这让用户更容易理解安静的等待时段，区分压缩与请求停滞。

调度器拥有的工具许可限制并发调用，并在后台交接期间保留所有权。被放弃的启动请求会被拒绝，超时后的约束清理在工具任务停止前完成。后台完成通知和操作系统状态探测移出注册表的阻塞路径；会话结束也避免同步持久化屏障。检查点写入器合并排队工作，并限制积压和载荷大小，避免存储压力拖住所有智能体。
## 更明确的配置与审批
由模式定义的设置 API 支持部分更新，Assistant 可发现配置并以只读方式查询项目。审批对话框和通知展示请求身份、权限及执行状态。通知范围、焦点处理、权限提示和减少动态效果的行为均得到改进。

项目感知的 Assistant 会话也将隔离对话、上传和任务跟踪纳入本版本；[项目工作流文章][workflow] 详述了这些交互。显式的本地技能清单命令可跳过工具权限检查，自动提交回退则处理智能体遗漏提交或提交失败的情况。
## 升级后检查恢复结果
对于已有的无头服务器安装，[版本化升级指南][update] 提供以下命令：
```bash
genesis update --check
genesis update
```
检测到可用更新时，检查命令以代码 10 退出。升级前先让活动工作完成；升级器检查服务器活动、准备新版本、重启并验证健康状态。在新版本中，正在暂停的任务仍会阻止升级，已暂停的任务可恢复且不阻止升级。Release 页面提供 Linux x64、Linux ARM64 和 macOS ARM64 的全新服务器安装包。

数据库升级现在使用常规迁移，不再要求独立的历史协调步骤。旧身份冲突通过增量协调处理，残留或不完整迁移状态会被拒绝。SQLite 修复路径仅用于开发。未使用的恢复辅助函数和一个完成别名从公共 API 移除，自定义集成应核对这些移除项。

依赖更新包含 Plug 1.20.4 的 multipart 长度限制安全修复与 ReqLLM 1.31.0，Nix 依赖哈希及预检也已刷新。升级后确认服务器报告的版本和健康状态，再尝试一个小型持久任务：暂停、确认检查点、恢复同一任务，并检查子智能体结果与活动标签。处理部署相关迁移诊断时，可对照[完整发布说明][release]。
